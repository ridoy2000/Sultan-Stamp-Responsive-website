# SultanStamp Website

![SultanStamp Logo](images/Black%20logo%20-%20no%20background.png)

The official website for Sultan Stamp, a creative design and printing company based in Dublin, Ireland. This site is actively deployed and serving customers at [sultanstamp.com](https://www.sultanstamp.com).

## 🚀 Live Deployment
- **URL**: [https://www.sultanstamp.com](https://www.sultanstamp.com)
- **Status**: Actively maintained and serving production traffic
- **Hosting**: AWS (Amazon Web Services)
- **DNS**: Managed through AWS Route 53

## 💻 Technologies Used

### Frontend
- **HTML5**: Semantic markup with modern structure
- **CSS3**: Custom styling with animations and responsive design
- **JavaScript**: Client-side interactivity and form handling
- **Bootstrap 5.3**: Responsive framework for layout and components
- **Font Awesome 6**: Icon library
- **Google Fonts**: Montserrat and Open Sans typography

### Backend & Services
- **Formspree**: Form submission handling
- **AWS S3/CloudFront**: Static website hosting with CDN
- **GitHub**: Version control and code repository

## ✨ Key Features
- Fully responsive design (mobile, tablet, desktop)
- Interactive image gallery with lightbox
- Animated carousel with auto-sliding
- Contact form with validation and submission handling
- Smooth scrolling navigation
- Optimized performance with lazy loading
- Accessibility considerations
- Modern UI/UX design principles
